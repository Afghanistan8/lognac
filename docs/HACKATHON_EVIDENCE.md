# Submission evidence checklist

The [official neatHack page](https://neatlogs.com/hackathon) asks for a public repo with hackathon-window commits, a demo video of at most three minutes, and verifiable use of neatlogs, Entire and cfo.ai. Do not mark an item complete until the linked evidence exists.

| Evidence | Status | Link or action |
| --- | --- | --- |
| Public Lognac repository, commits October 10–12 2026 | Pending push | `https://github.com/Afghanistan8/lognac` |
| neatlogs trace of a baseline review | Pending API key and run | Add trace link |
| neatlogs trace of the retry/recovery run | Pending API key and run | `npm run demo -- --failure`; add trace link |
| Before/after measurable improvement | Pending two saved traces | Compare finding coverage, retry completion, duration and cost; report actual numbers |
| Entire checkpoint or graph output | Pending checkpoint | Enable/login, commit, verify checkpoint link or output |
| cfo.ai business plan | Pending cfo.ai workspace | Import the assumptions in `BUSINESS_MODEL_DRAFT.md`, verify calculations, export and link the result |
| Public build update tagged `#neatHack` | Pending owner post | Add link |
| Video covering all three partner tools | Pending recording | Add link; show architecture, failure recovery, written result, graph, traces, checkpoint and finance plan |
| Official X quote-post submission | Pending October 12 submission window | Add published link |

The local planner is an offline fallback. For a model-planned trace, provide an OpenAI-compatible model key in `.env` and verify the UI says **Model planner active**. A configured Neatlogs key is necessary for externally verifiable traces. Do not publish API keys or fictional email credentials.
